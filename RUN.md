# Run SOLIS

## 1) Install once
```bash
./setup.sh
```

## 2) Generate an image
```bash
./run.sh
```
- This asks for a prompt.
- It saves the image and opens it automatically on Raspberry Pi desktop.

## Optional: custom prompt
```bash
./run.sh --prompt "A clean energy city at sunset"
```

## Output
- `output/solis_latest.png`
