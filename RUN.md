# Run SOLIS

## Command
```bash
./run.sh
```

## What You’ll See
- A fullscreen window opens and begins rendering a renewable-energy themed artwork.
- The image evolves as diffusion steps complete.
- The final image remains on screen until you exit.

## Platform Note
- This run guide assumes a macOS or Linux desktop/laptop. Raspberry Pi is not a supported target for the default model.

## Controls
- `Esc` or `q`: exit fullscreen.

## Output
- Final image: `output/solis_latest.png`
